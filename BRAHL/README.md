# BRAHL (in FoXYiZ_User)

Desktop Arena UI for this package. Start with `Run BRAHL.bat` from the FoXYiZ_User root.

- App: http://127.0.0.1:8766/app
- Engine: `FoXYiZ\f\FoXYiZ.exe` (not Python engine source)
- `FOXYIZ_ROOT` = `<FoXYiZ_User>\FoXYiZ` (set by the bat)
- Demo suites: Math, API_Petstore, UI_internet, BRAHL_Local under `FoXYiZ\y\`

Requires Python for the local web server only. The test engine is the frozen exe.
